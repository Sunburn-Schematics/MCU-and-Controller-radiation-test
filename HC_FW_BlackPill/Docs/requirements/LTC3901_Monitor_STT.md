## External command transitions

The LTC3901 manager accepts these external commands:

- `RUN`: transition from the current state to `POWER_UP`, then continue through normal state-machine flow.
- `HALT`: transition from the current state to `HALT`. HALT disables `nLTC3901_Pwr_En`, `SDRA_DRV`, and `SDRB_DRV`, but preserves `Power_Fault_Count` and `Sync_Fault_Count`.
- `RESET`: transition from the current state to `RESET`. RESET disables `nLTC3901_Pwr_En`, `SDRA_DRV`, and `SDRB_DRV`, and clears `Power_Fault_Count` and `Sync_Fault_Count`.

`HALT` is only entered via external command. Internal fault or timing transitions do not enter `HALT`.
