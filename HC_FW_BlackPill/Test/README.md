# Hardware Tests

This folder contains hardware-in-the-loop test inputs and generated test review
artifacts for the STM32 target.

Contents:
- `hw_test_cases.json` is the data-driven JSON protocol test suite consumed by
  `Tools/test.ps1`.
- `Reports/` contains durable Markdown and JSONL artifacts generated by hardware
  test runs.

Run the default hardware test workflow with:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File Tools\test.ps1 -Build -Program -ContinueOnFail
```

The runner also writes short-lived run-local output under
`build/<Preset>/hw_tests/<timestamp>/`; durable review copies are archived under
`Test/Reports/`.
