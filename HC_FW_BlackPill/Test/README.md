# Hardware Tests

This folder contains hardware-in-the-loop test inputs and generated test review
artifacts for the STM32 target.

Contents:
- `hw_test_cases.json` is the data-driven JSON protocol test suite consumed by
  `Tools/test.ps1`.
- `hw_fault_injection_cases.json` is an intrusive hardware manager-state suite
  that intentionally changes remote manager thresholds and timers to exercise
  DUT manager state and fault paths. Its cleanup tail restores manager
  thresholds, confirms both managers can be commanded back to `RUN`, and then
  issues `hc_cmd: RESET` so runtime state is reinitialized.
- `Reports/` contains durable Markdown and JSONL artifacts generated by hardware
  test runs.

Run the default hardware test workflow with:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File Tools\test.ps1 -Build -Program -ContinueOnFail
```

The runner also writes short-lived run-local output under
`build/<Preset>/hw_tests/<timestamp>/`; durable review copies are archived under
`Test/Reports/`.

Run the fault-injection suite only when it is acceptable to drive the DUT manager
power-control paths and temporarily alter runtime thresholds:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File Tools\test.ps1 -CasePath Test\hw_fault_injection_cases.json -ContinueOnFail
```
